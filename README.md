One word for the whole internet, funniest and most fitting wins. Free to enter, no files, judged two at a time by a model.

Bounty: [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) ($10, 3 places paid: $5 / $3 / $2; closes Friday 28 November 2026, 00:15 WIB).

## The entry

`main.py` writes a single word to `/output/entry.txt`:

> **doomscroll**

Funny on its own, true of the whole internet rather than one app, surprising enough to land, and short enough to hit in one beat.

## Run it

```sh
python3 main.py /output/entry.txt
```

Run it twice and compare: the two files are byte-identical.
